# v0.2.0 candidate

Prepared against the published v0.1.1 baseline. No v0.2.0 tag or release has
been published. This candidate includes named identities, upload splitting,
and saved-chat templates in addition to the fixes below.

## Changes

- `nlm sync --auto-split` can split server-rejected uploads into smaller txtar
  parts. It retains the resulting layout across runs, preserves source-family
  labels, and excludes authentication and rate-limit failures from splitting.
  Replacement and cancellation cleanup preserve labels and completed uploads.
- Sync writes local attempt receipts and emits a final `action: "result"`
  event in JSON mode. Duplicate family titles and sources already marked
  `error` stop sync before mutation. Existing RPC exit classes are preserved;
  completion describes upload and cleanup operations, not indexing readiness
  or atomic family replacement. See [sync receipts](../dev/sync-receipts.md).
- `nlm auth login --as NAME`, `auth list`, `auth use`, and `auth remove` manage
  named identities. `--identity` and `NLM_IDENTITY` select one explicitly.
- The public `nlmauth` package supports stored credentials and named sessions.
  Sessions are stored in local files with restricted permissions.
- `nlm chat show --template FILE` renders saved conversations with a Go
  text/template. Repeatable `--template-var key=value` supplies metadata;
  `--out` writes Markdown as well as HTML. See the
  [template schema and examples](../dev/chat-templates.md).
- HTML renders Markdown carried alongside rich citation metadata, including
  headings, lists, bold, quotes, and HTTP(S) links. Generated trailing follow-up
  prompts are omitted by default; `--include-follow-ups` retains them.
  Shared and repeated grounded passages retain all citation associations.
  Passage buttons highlight the matching text on hover or keyboard focus;
  long source rails flow with the page. Source excerpts preserve their text
  instead of guessing table boundaries or decoding literal escape sequences.
  Application-specific link resolution belongs to external report tools.
- `generate-chat --conversation` appends exchanges instead of overwriting the
  saved transcript. Prefix lookup retains a locally saved full conversation ID.
  `chat show --backfill` merges available missing turns and citation metadata
  while preserving local text and reasoning.
- Revised streamed answers remain available through `chat show --last`.
  Stale captured output exits 8; incomplete runaway output exits 10.
  UTF-8 revisions retain character boundaries. Long response frames, initial
  waits, browser-auth diagnostics, and terminal cleanup are improved.
- NotebookLM credential refresh rejects cross-origin and HTTPS-to-HTTP
  redirects. PDF sources are identified as PDFs.

## Compatibility and upgrade

Go 1.25 or newer is required. Existing CLI commands and package signatures
remain available. `notebooklm.Client.GetConversationHistory` now returns its
recent messages in chronological order; consumers that reversed its previous
newest-first output should remove that reversal. Its request asks for at most
20 recent messages. Backfill reports an empty server response as an error;
it cannot restore messages the server does not return.

Legacy `~/.nlm/env` credentials migrate to identity `default` on first use.
The selected identity continues to have an `env` compatibility mirror. The identity store is not transactional across files and does
not coordinate concurrent writers. See the
[identity storage contract](../dev/multi-profile-design.md).

Before upgrading an unattended installation, stop its jobs and retain a private
copy of its local state:

```sh
backup="$HOME/tmp/nlm-before-v0.2.0-$(date +%Y%m%d-%H%M%S)"
mkdir -m 700 -p "$backup"
cp -Rp "$HOME/.nlm" "$backup/nlm"
```

After installation, check `nlm --version` and `nlm auth list`, render a saved
conversation, and inspect `nlm sync --dry-run NOTEBOOK DIRECTORY` before resuming
sync. Start with an explicit `--identity` where account selection matters.
Automatic splitting remains opt-in. JSON sync consumers
must handle the final result event and treat a missing or incomplete result
as unfinished work. Attempt receipts are retained locally without automatic
pruning; a successful sync is not proof that indexing succeeded.

## Release gates

Run from a clean checkout with workspace mode disabled, so sibling checkouts
cannot supply unpublished dependencies:

```sh
export GOWORK=off
go mod verify
go build ./...
go vet ./...
go test ./...
go test -race ./...
go test -tags integration -run XXXNONE ./...
go install golang.org/x/tools/cmd/deadcode@v0.44.0
deadcode -test -tags integration \
  -filter='^github.com/tmc/nlm/cmd/nlm$' ./cmd/nlm
git diff --check
```

The deadcode output must be empty. Tracked Go files must also be gofmt-clean.
Build rehearsals should cover darwin/arm64, darwin/amd64, linux/amd64,
linux/arm64, and windows/amd64 with `CGO_ENABLED=0`. Cross-builds establish
compilation, not operating-system runtime behavior. Run the tests separately
on the minimum supported Go version as well as the release toolchain.

Live cross-account behavior requires separate runtime verification.
Read visibility is not proof of upload permission; use explicit identity
selection when needed. Backfill cannot recover history the server
no longer returns.

## Publication

Once the reviewed candidate is approved for publication, check that the remote
has not advanced and that v0.2.0 does not already exist. Then publish the branch
and annotated tag:

```sh
git push origin main
git tag -a v0.2.0 -m 'nlm v0.2.0'
git push origin v0.2.0
```

Verify installation from a separate directory with workspace mode disabled:

```sh
GOWORK=off go install github.com/tmc/nlm/cmd/nlm@v0.2.0
nlm --version
nlm chat show --help
```

This tagged installation and remote CI can only be verified after publication;
the local preparation did not perform either operation.

## Rollback

If identity selection or rendering regresses, pause unattended jobs and restore
the previous binary:

```sh
GOWORK=off go install github.com/tmc/nlm/cmd/nlm@v0.1.1
nlm --version
```

The previous version reads the current `~/.nlm/env` mirror. Keep the new named
identities and saved chats; restoring the entire backup would discard newer
local history. Remove `--identity`, template flags, and `--auto-split` from jobs
using the older binary. A binary downgrade does not undo uploaded sources or
label changes. Review a sync dry run before resuming jobs against notebooks
that now contain split sources.
